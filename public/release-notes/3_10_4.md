## Addressed Issues

* Fixed a bug where opening a network in Cytoscape from Cytoscape Web incorrectly set the collection name to `?(SUID: ##)`.
* Fixed a bug where styles were corrupted if **Show Tasks** was opened at any time before invoking close session.
* Fixed bug where moving a group of nodes fails after reloading in Cytoscape.
* The “Layout only selected nodes” control in the **Layout Settings** dialog is now a button labeled **Apply to Selected Nodes**, making the action more explicit and easier to use.
