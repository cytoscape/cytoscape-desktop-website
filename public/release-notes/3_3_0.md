Cytoscape 3.3 is a Cytoscape Desktop version with new features and bug fixes.

____

## Improvements

### Cleaner User Interface
Cytoscape 3.3 has a cleaner, more intuitive user interface. This includes:
  * Improved network and table file importer.
  * New icons for the toolbar.
  * Aesthetic and consistency improvements in many dialogs.

![Table Import](/release-notes/images/cy_3_3_0_ui_tableimport.png)

### Improved Filter
Filters can select based on properties of adjacent nodes and can edit selections.

![Filter](/release-notes/images/cy_3_3_0_filter.png)

### Improved Group Visualization
Groups can be visualized as compound nodes.

![Compound Node](/release-notes/images/cy_3_3_0_group.png)

### Core Apps
Some of the Cytoscape core features are now released as independent Core Apps. This means you can get more frequent updates for those features.

### Bug Fixes
This release includes many bug fixes. Addresses 193 issues relative to v3.2.1.

### Integrated RESTful API
cyREST is now a part of core distribution as a core app. Both cyREST API and Commands are accessible from same port.

![cyREST](/release-notes/images/cy_3_3_0_rest.png)

### Performance
  * **Faster Network Analyzer**
    * Network Analyzer is optimized and is up to 1000 times faster than previous version.
    
      ![Network Analyzer Statistics](/release-notes/images/cy_3_3_0_networkanalyzer.png)

  * **GPU-Based Layout**
    * Force-directed layout algorithm is optimized via GPU. It is up to 100 times faster than CPU-based layout.

      ![GPU Layout Settings](/release-notes/images/cy_3_3_0_gpulayout.png)

## System Requirements

* **Continuing 32 bit OS Support, Deprecating Java 6 & 7 Support**
  * While v3.3 continues to support 32 bit OSs, it no longer supports Java 6 or 7. We plan to support 32 bit OSs as long as we can, but will eventually drop this support. Desupporting Java 6 and 7 matches current industry practice, and allows us to focus our resources on more advanced feature development.
  * Java 8 is Required.

### Windows

  * Windows XP and newer (including Windows 7, 8 and 10). **64 bit version is recommended**.
  * Latest version of [Java from Oracle](https://www.oracle.com/technetwork/java/javase/downloads/jre8-downloads-2133155.html). OpenJDK and other implementations are not tested.
Note that the java.com website installs a 32 bit JVM by default (to match Windows’ 32 bit browsers). To download a 64 bit JVM, use [this page](https://www.oracle.com/technetwork/java/javase/downloads/jre8-downloads-2133155.html).

### Mac

  * Mac OS X 10.9 (Mavericks) and later.
  * Latest version of [Oracle Java](https://www.oracle.com/technetwork/java/javase/downloads/jre8-downloads-2133155.html).

### Linux

  * Tested on [these distributions](https://docs.google.com/spreadsheets/d/1dkP-82icfrdQp3vqt8HqzeyGb_iwgrqg3OxJaqOuWiI/edit#gid=0&vpid=A1).
  * Latest version of Java is required (minimum Java 8 Update 72).
  * For Ubuntu, a simple way of installing the Oracle JVM is described here.

## Known Issues

### Missing Scrollbars on Linux
A bug in Java 8 Update 60 (also present in 65/66) causes scrollbars to not always appear on Linux systems. This occurs on both OpenJDK and Oracle Java releases (including the OpenJDK shipped with Ubuntu 15.10 and some other recent Linux distributions), and is resolved by installing Java 8 Update 72 or later from Oracle.

### Internationalization (PDF Export)
For Japanese, Korean, and Chinese users, rendering a network to a PDF file can result in loss of labeling information in the PDF. As a workaround, users can generate any type of image file and use the image file instead.

### Proxy Settings
On Linux, on the proxy configuration dialog box, fonts are clipped and messages are truncated.

### Conflict with Older Versions
On all platforms, users installing Cytoscape directly from a ZIP or TAR file should manually clear the Cytoscape cache by deleting the CytoscapeConfiguration folder in the user’s home directory.

### File Encoding
On all platforms, all Cytoscape session files recorded since v3.0.1 are encoded in UTF-8 instead of the native language encoding. This makes session files portable between workstations in all locales. Users in Japan, Korea, and China are most affected – existing v3.0.0 or v2.x session files must be translated to UTF-8 using a platform-dependent editor (which most users are already using for this purpose). Users in Europe and the Americas are affected, too, if they use characters beyond the standard ANSI 128 – they can translate to UTF-8 using a platform-dependent editor (e.g., Notepad for Windows).

### Missing Columns After Loading Multiple Networks
When loading multiple networks into the same network collection, it is important to import tables only after each of the networks is loaded. Interspersing table imports with network loads may cause some table columns to become inaccessible to some networks.

### Installing on Ubuntu 15.10 (64 bit)
The Cytoscape installer does not run on non-root accounts using the default OpenJDK JVM. It works properly with Oracle Java 8 Update 71 or higher, or as root with OpenJDK. Alternatively, Cytoscape can be installed by downloading and unzipping the GZIP archive found via the **Other Platforms** link on the Download section.

### Fedora 21+: Headless Java
Fedora 21 (or later) installs a headless (non-GUI) version of Java by default. As a GUI application, Cytoscape will not install or run with this version of Java. To use Cytoscape on Fedora 21 (or later), one will need to install a standard version of Java. The OpenJDK JRE is available from the Fedora package repository - simply install the java-1.8.0-openjdk.x86_64 (for 64-bit) or java-1.8.0-openjdk.i686 (ofor 32-bit) packages. Oracle’s JRE is available for download in RPM format at java.com, though this requires extra configuration.

### Fedora 21+: Blank Startup Screen
On Fedora 21 (or later), the Cytoscape splash screen may appear blank on startup. This does not affect the operation of the Cytoscape application, and can be resolved by upgrading to Fedora 23 with latest patches.
